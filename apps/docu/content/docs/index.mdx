## Features

- Portable architecture that avoids vendor lock-in
- REST API starter with OpenAPI support
- Type-safe SDK generation from OpenAPI specs
- Self-hosted Web2 and Web3 authentication, JWT and refresh tokens
- Designed for Multichain support ( EVM, Solana, Cosmos )
- Minimal boilerplate for AI features
- Automated security scanning and testing
- Smart contract development environments
- AI-assisted development workflow
- Monorepo with shared packages and clear app boundaries
- Consistent conventions across frontend, backend, and tooling
- Documentation for developers and AI agents
- Robust logging and error handling strategies
