**Basilic** is an API-First AI TypeScript FullStack Starter: a Fastify REST API with OpenAPI-generated clients, self-hosted Web2 auth (Web3 on the API, no web wallet UI), and a shared `AGENTS.md` contract with Basilic `/w-*` playbooks and **stack skills** in git. Any coding agent or IDE that can read those files. Fastify `/ai/generate` is optional [API chrome](/docs/architecture/ai), not the Product Ready bar. Interactive Chat is eve. The dashboard composer lives on the coin board. Shared packages keep web, mobile, and docs consistent.

LLM-friendly index: [`/llms.txt`](/llms.txt) (table of contents) and [`/llms-full.txt`](/llms-full.txt) (full text dump).
