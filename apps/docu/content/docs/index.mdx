**Basilic** is an API-first foundation for agentic products. Define capabilities on the Fastify API once. Web, CLI, generated SDKs, coding agents, and durable eve agents consume that contract.

API-first here means humans are not the only clients. Session JWTs serve the browser. API keys serve the CLI, scripts, and other machine callers. eve runs `command` and `chat` on a sibling host. Generative UI (Jev, json-render, shadcn/Base UI) is how agents compose the web surface. There is no product MCP.

This repository includes `apps/agents`. [`create-basilic`](/docs/development) omits agents until a later release. Clone this repo for the full reference. Fastify `/ai/generate` is optional [API chrome](/docs/architecture/ai), not the [Product Ready](/docs/testing/product-ready) bar.

Start with [Getting Started](/docs/development). Architecture and the capability set live under [Architecture](/docs/architecture).
