**Basilic** is an opinionated TypeScript product foundation for Vercel-oriented workflows. Own the API; hang web, mobile, and coding agents off it.

Fastify is the control plane (OpenAPI, auth, agent discovery). [Eve](/docs/architecture/eve) runs command and chat on a sibling host. Next.js is a typed client (coin-tracker sample, json-render board). `AGENTS.md` and stack skills serve coding agents. Fastify `/ai/generate` is optional [API chrome](/docs/architecture/ai), not the [Product Ready](/docs/testing/product-ready) bar. **This repository** includes `apps/agents`; [`npx create-basilic`](/docs/development) omits agents until a later release — clone this repo for the full Agent Stack reference.

LLM-friendly index: [`/llms.txt`](/llms.txt) (table of contents) and [`/llms-full.txt`](/llms-full.txt) (full text dump).
