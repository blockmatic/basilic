Branch from `main`, PR, automated checks, CodeRabbit + human review, merge, deploy. Lint and `security.yml` run on every PR. App E2E and package tests are path-filtered. Mobile EAS: [Mobile CI/CD](/docs/deployment/mobile-cicd). Workflows: [GitHub Actions](/docs/deployment/github-actions).

**Vercel** for web/API/docs previews. Shipped path is Vercel + Supabase — [Portability](/docs/architecture/portability) (GCP/AWS are not first-class). In-app LLM on your hardware: [Self-Hosted LLM](/docs/deployment/self-hosted-llm). npm dual-mode exports: [Publishing](/docs/deployment/publishing).
