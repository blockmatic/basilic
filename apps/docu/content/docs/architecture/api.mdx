Fastify routes and TypeBox schemas are the source of truth for validation and for the OpenAPI spec. `@hey-api/openapi-ts` generates the TypeScript client in `@repo/core`. `@repo/react` wraps that client with **handwritten** TanStack Query 5 hooks — Hey API does not generate them.

Flow: TypeBox → OpenAPI → `@repo/core` (client + types) → handwritten `@repo/react` hooks. Commands: [OpenAPI Generation](/docs/development/openapi-generation).

## Stack

- Runtime: Node.js 24.x (LTS Krypton)
- Framework: Fastify 5, TypeBox, ESM
- Database: PostgreSQL via `DATABASE_URL`. PGLite when `PGLITE=true` or `NODE_ENV=test`. SQL assets must sit next to compiled `migrate.js`; an empty list is a hard error in those modes. Details: [ADR 008](/docs/adrs/008-database).
- ORM: Drizzle
- Spec: OpenAPI 3 at `apps/api/openapi/openapi.json`, UI at `/reference`. Tags: `auth`, `account`, `ai`, `coins`, `health`. The `ai` tag is `POST /ai/chat` and `POST /ai/generate` — optional demo assistant, documented in [AI](/docs/architecture/ai).

`GET /coins` is a JWT list of cached CoinGecko markets joined to identity `assets` (seeded when the registry is empty). Optional SearchQuery querystring filters (`universe`, `symbols`, `text`, `topN`, `sortBy` / `sortDir`, min/max change and price, `highlight`) apply in process to that cached list; `POST /coins/query` accepts the same object as JSON. Quotes are the same for every authenticated user except `universe=watchlist`, which uses `listWatches` for the access JWT `sub`. JWT watch CRUD is `GET` / `PUT` / `DELETE /coins/watches` keyed by identity asset id (`bitcoin`), not `geckoId` — empty GET is `[]`, PUT is idempotent, cap 20 is 409 `WATCHLIST_FULL`, and DELETE is 204 if missing. Vendor failure returns fixture quotes with `sync.source: 'fixture'` (HTTP 200). `sync.source` is `live`, `fixture`, or `stale`. Live responses include `sync.attribution` (`Data by CoinGecko`). Optional `sync.stale` is true when the in-process cache is served past TTL. Every 200 includes `query`, `spokenSummary`, and `queryCaption`.

Vendor HTTP lives in `@repo/markets`: CoinGecko Demo via `@coingecko/coingecko-typescript`, Binance public REST on `data-api.binance.vision`, an in-process TTL cache with a `get`/`set` port, and an SSRF allowlist. `GET /coins`, `POST /coins/query`, and `getMarketSnapshot` all call `getMarkets`. Optional `COINGECKO_DEMO_API_KEY`, `MARKETS_CACHE_MS` (default 300000), `COINS_USE_FIXTURE` (E2E spawn sets `true` so quotes stay on the checked-in fixture), and `COIN_MAJOR_SYMBOLS` (default `btc,eth,sol`) are in api `lib/env.ts` and passed into `configureMarkets`. `GET /coins`, `POST /coins/query`, and `/coins/watches` use a tighter route rate limit (`COINS_RATE_LIMIT_MAX`, default 10) than `/ai/*` (`AI_RATE_LIMIT_MAX`, default 20). Authenticated `GET /agents` lists eve `command` and `chat` origins (`EVE_COMMAND_URL`, `EVE_CHAT_URL`). There is no Alchemy client in this package.

## How it works

1. Author a route with TypeBox in `apps/api/src/routes/` (one file per endpoint).
2. Generate OpenAPI from those routes.
3. Generate `@repo/core`. Add or update hooks in `@repo/react` by hand when the UI needs them.

Runtime: request → Fastify validation → handler → Drizzle → JSON.

```typescript
import { Type } from '@sinclair/typebox'
import { dbHealth } from '../db/probe.js'

fastify.get('/health', {
  schema: {
    response: {
      200: Type.Object({ ok: Type.Boolean(), dbReady: Type.Boolean() }),
      503: Type.Object({ ok: Type.Boolean(), dbReady: Type.Boolean() }),
    },
  },
}, async (_request, reply) => {
  const dbReady = await dbHealth.probe()
  if (!dbReady) return reply.code(503).send({ ok: false, dbReady: false })
  return reply.code(200).send({ ok: true, dbReady: true })
})
```

`GET /health` is readiness: **200** when `SELECT 1` succeeds, **503** when the store cannot answer. It does not probe Resend, AI, or IdPs.

`GET /` is a content-first landing for humans and agents. It keeps the title **Basilic Fastify API**, advertises `is-agentic-site-type=app`, and includes JSON-LD `WebAPI`. Send `Accept: text/markdown` for markdown (`Vary: Accept`; **406** when Accept matches neither HTML nor markdown). Unknown paths are real **404**s: JSON clients get catalog `NOT_FOUND` plus optional RFC 9457 fields (`Accept: application/problem+json` when asked); HTML and markdown clients get a short recovery body with links to `/`, `/llms.txt`, `/sitemap.xml`, and `/openapi.json`. 401 responses send `WWW-Authenticate`; 429 responses send IETF `RateLimit` / `RateLimit-Policy` / `Retry-After` as well as `x-ratelimit-*`. See [Error Handling](/docs/architecture/error-handling). The landing also links `/reference`, `/openapi.json`, `/health`, `/robots.txt`, the docs site, and web privacy/terms. The Fastify host serves `/robots.txt`, `/sitemap.xml`, `/llms.txt`, `/.well-known/api-catalog` (RFC 9727), and `/.well-known/oauth-protected-resource` (RFC 9728) without authentication. Live OpenAPI is `GET /openapi.json` (`Accept: application/openapi+json` when asked); `/reference/openapi.json` is the same document.

`createClient` from `@repo/core` has three auth modes (see [Authentication](/docs/architecture/authentication)): no-auth, JWT (`getAuthToken` / refresh), API key.

```typescript
import { createClient } from '@repo/core'
import { useHealthCheck } from '@repo/react'

const client = createClient({ baseUrl: process.env.NEXT_PUBLIC_API_URL! })
const { data } = useHealthCheck()
```

Other languages can use any OpenAPI generator against the same spec. Local DB: `pnpm reset` (Supabase reset + Drizzle migrate + seed). See [ADR 008](/docs/adrs/008-database).

## Security

Security headers, CORS via `ALLOWED_ORIGINS`, per-IP rate limiting, TypeBox validation, `trustProxy` behind a reverse proxy. Details: [Security](/docs/architecture/security).
