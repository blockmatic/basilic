Four planes:

- **Control** — Fastify product HTTP. `POST /ai/generate` and `POST /ai/enhance` are the `/ai/*` routes. Interactive dashboard Chat uses eve.
- **Interaction and execution** — eve on a separate host. Public agents `operator` and `ask` live in `apps/agents` — [Agents](/docs/architecture/agents) and [Eve](/docs/architecture/eve). Not a Fastify proxy. No coordinator agent.
- **Domain** — `@repo/db` named functions, `@repo/markets` vendor HTTP, and `@repo/onchain` wallet HTTP. Next keeps `@repo/core`.
- **Presentation** — Generative UI on the home Agent surface: operator `set_view` commits `q` and `surface`; Next renders status/account specs via `apps/web/lib/genui` and `apps/web/components/genui/registry`. Coin Tracker adds board Jev and `composeSpec` on Send; the starter does not.

Models are implementation details; agents are product capabilities (`operator`, `ask`). Fastify `POST /ai/generate` and eve language models use `ANTHROPIC_API_KEY` (Haiku default `claude-haiku-4-5`). Jev (`typesafe-ai/jev`) uses Vercel AI Gateway on eve (`AI_GATEWAY_API_KEY` or `VERCEL_OIDC_TOKEN`) and never uses the Anthropic key. Coin Tracker runs Jev triage on operator; Ask uses Anthropic only. Runtime decision: [ADR 014](/docs/adrs/014-fastify-eve-vercel-runtime).

Fastify `/ai/generate` is **control-plane API chrome**, not the Product Ready bar and not the durable agent runtime. Agent **skills** (`AGENTS.md`, Basilic `/w-*`) live in [AI Workflow](/docs/development/ai-workflow) — not this page.

The Fastify API exposes two AI endpoints under `/ai/*`. Implementation lives in `apps/api/src/lib/ai/`; route files in `apps/api/src/routes/ai/` are thin handlers (schema + auth + delegation). The browser talks to Fastify directly (Bearer). There is no Next.js AI BFF.

There is no first-class OpenAI SDK, no RAG or embeddings, no chat message store, no `ToolLoopAgent`, and no mobile assistant. Generate is `streamText` / `generateText` with `maxOutputTokens` from `AI_MAX_OUTPUT_TOKENS` (default 4096). `body.model` is an allowlist (`default`, `haiku`, `sonnet`, `anthropic/claude-haiku-4.5`, `anthropic/claude-sonnet-4.6`, plus `AI_DEFAULT_MODEL` when set). Unknown ids including `opus` are 400. Legacy Gateway slugs (`anthropic/claude-haiku-4.5`) map to direct Anthropic ids. `POST /ai/generate` uses a tighter route rate limit (`AI_RATE_LIMIT_MAX`, default 20) than global `RATE_LIMIT_MAX`. `GET /coins` is tighter still (`COINS_RATE_LIMIT_MAX`, default 10).

## Routes

| Route | Use case | Response |
| --- | --- | --- |
| `POST /ai/generate` | CLI, scripts, single prompt | JSON `{ text }` or UI-message SSE |
| `POST /ai/enhance` | Rewrite a draft before send (command, Ask, CLI) | JSON `{ text }` |

Bearer auth is required (session JWT or API key). Set `Accept: text/event-stream` or `stream: true` for SSE on generate. Generate is prompt-only (no tools). Enhance uses a fixed system instruction and returns one rewritten prompt; it does not send to eve. Interactive Ask is the eve `ask` agent — [Eve](/docs/architecture/eve). Fastify does not expose `POST /ai/chat`.

## Enhance prompt

The home command composer and Ask tab expose **Enhance**. It calls `POST /ai/enhance` with the current draft, replaces the field with the improved text, and does not send. You edit the result, then send. Naming the stack and style yourself still steers the agent; Enhance is not a substitute for that.

The model fixes typos, misspellings, and speech-to-text errors. Thin drafts expand into one clearer prompt. When the draft is about UI and names no stack, the rewrite may suggest React, Tailwind, and shadcn/Base UI.

Example:

- Draft: `develop a contex sales form`
- Improved prompt: `Build a contact sales form with React, Tailwind, and shadcn/Base UI. Include name, work email, company, and a message. Use one column on small screens.`

## Provider

`getResolvedProvider()` in `lib/ai/provider.ts` returns `anthropic` when `ANTHROPIC_API_KEY` is set, otherwise `null` (500 `SERVER_ERROR`). Fastify generate and eve `operator` / `ask` language models use `@ai-sdk/anthropic`. Default model is Claude Haiku 4.5 (`claude-haiku-4-5`). Request alias `sonnet` maps to `claude-sonnet-4-6`. Jev on eve (and Coin Tracker composeSpec) uses `createGateway` from `ai` with `typesafe-ai/jev`.

## `lib/ai` layout

```
apps/api/src/lib/ai/
  index.ts           named re-exports
  provider.ts        getResolvedProvider, getProvider, model allowlist
  route-rate-limit.ts /ai/* Fastify rateLimit config
  runtime.ts         abort, SSE piping, upstream error mapping
  upstream-error.ts  isInsufficientCreditsError
```

Shared runtime handles client abort + `AI_UPSTREAM_TIMEOUT_MS`, v7 UI streams (`toUIMessageStream` + `createUIMessageStreamResponse`), and catalog errors via `captureError` then `sendCatalogError`.

Eve Chat sanitizes inbound session payloads: client `{ role: 'system' }` messages are rejected, and file parts must use `data:` URLs only. Remote URLs (`http:`, `https:`, `file:`, etc.) are rejected in `apps/agents/lib/ingress.ts` (`isAllowedChatFileUrl` / `inspectSessionPayload`). That matrix lives on eve, not on Fastify generate.

## Environment variables

| Variable | Required | Default | Description |
| --- | --- | --- | --- |
| `ANTHROPIC_API_KEY` | Conditional | — | Anthropic API key. Unset yields 500 on generate |
| `AI_GATEWAY_API_KEY` | Conditional | — | Vercel AI Gateway for Jev on eve (and DeepSec). Not used for generate |
| `VERCEL_OIDC_TOKEN` | Conditional | — | Gateway auth on Vercel deploy (Jev) |
| `AI_DEFAULT_MODEL` | No | `claude-haiku-4-5` | Anthropic model id |
| `AI_MAX_OUTPUT_TOKENS` | No | `4096` | Completion cap (`maxOutputTokens`) |
| `AI_RATE_LIMIT_MAX` | No | `20` | Per-route `/ai/*` max in the rate-limit window |
| `AI_UPSTREAM_TIMEOUT_MS` | No | `120000` | Upstream abort timeout (ms) |

Templates: `apps/api/.env.defaults.example`, `apps/api/.env.test.example`, `apps/agents/.env.defaults.example`. Eve does not read Fastify's `apps/api/.env`. Set `ANTHROPIC_API_KEY` on API and agents for language models. Set `AI_GATEWAY_API_KEY` (or OIDC) on agents for Jev (`JEV_MODEL`, default `typesafe-ai/jev`).

## Dashboard Chat (eve)

Presentation (board Spec, composeSpec / `specFromSelection` / `composeSurface`) is [Frontend](/docs/architecture/frontend). The Ask tab sends to eve `ask` with canvas context and does not call Fastify `/ai/*`. Catalogs in `apps/web/components/assistant` remain as chat fallbacks. `user-info-catalog` still feeds the board registry.

## Errors

Pre-stream failures map to catalog codes: 401, 400, 402 (`INSUFFICIENT_CREDITS`), 429 (`RATE_LIMIT_EXCEEDED`), 502 (`UPSTREAM_SERVICE_ERROR`), 504 (`UPSTREAM_TIMEOUT`). Response bodies use catalog messages only — never raw upstream `err.message`.

## Testing

- **API Vitest** (`ai.spec.ts`, `lib/ai/provider.spec.ts`): remote generate and enhance run when `ANTHROPIC_API_KEY` is set (not a placeholder). Skips **402** only for `INSUFFICIENT_CREDITS`. Skips 502/504 when the key is missing. Generate contract: 401 unauthenticated, 400 bad payloads, model allowlist, rate limit. Enhance contract: 401, 400 empty or whitespace prompts.
- Board chrome, eve Chat, and compose tests: [Frontend](/docs/architecture/frontend), [Eve](/docs/architecture/eve), and [E2E Testing](/docs/testing/e2e-testing). Dashboard Playwright still asserts Send paths do not hit `/ai/chat`. Missing SpeechRecognition hides the mic; keyboard Send still works. There is no Fastify chat Playwright project.
