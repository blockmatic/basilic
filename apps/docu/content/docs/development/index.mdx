Vercel is the default host. Local `pnpm` is still the first command.

## Prerequisites

Node.js **24.x (LTS Krypton)** is pinned in `.nvmrc` and `.node-version`. pnpm is pinned as `packageManager`: **12.4.2**.

```bash
nvm install lts/krypton
nvm alias default lts/krypton
nvm use
corepack enable
corepack prepare pnpm@12.4.2 --activate
```

## Setup

```bash
npx create-basilic@latest my-app
cd my-app
pnpm run setup
```

This repository is for contributing to Basilic and for running the **full reference** (including `apps/agents`). `create-basilic` is not published on npm `latest` yet (`0.0.0` in tree); until it is, clone here and use `pnpm setup` below. Generated apps use `docs/basilic/` instead of `apps/docu`. [After fork](/docs/development/after-fork) lists what to replace when the generated copy is your product.

`setup` installs dependencies, git hooks, **agent skills** (`blockmatic/basilic-skills` `/w-*`; lockfile hashes stay pinned), security tools, **Portless** (CA trust + HTTPS proxy), and database **tooling**. It also copies `.env.<qualifier>.example` templates to gitignored dest files when those dest files are missing. Copied local env sets `ALLOW_TEST=true` so `test@test.ai` works without Resend. Edit the copied files to set paid secrets. `setup` does **not** start Postgres.

## First run

```bash
pnpm db:start
pnpm dev
```

`pnpm db:start` is Supabase CLI in `@repo/db` (`packages/db/supabase/`). Fastify (and eve) apply Drizzle migrations on boot in development and seed identity when `assets` is empty. `pnpm reset` is a wipe (drop + migrate + seed), not a first-run requirement. See [ADR 008](/docs/adrs/008-database) and [Product Ready](/docs/testing/product-ready).

## Daily

```bash
pnpm dev
```

Ensures Docker Postgres is up, then starts Turborepo's TUI — the same left-pane task list as `pnpm lint:eslint` / `pnpm test`. Eve `dev` waits on `@repo/db#db:start`. Skip Docker with `SKIP_DB_START=1` (use that for PGLite-only generated apps). Click or arrow-key between logs. Ctrl-C stops Node watchers; Postgres stays up until `pnpm db:stop`.

This repo's TUI includes API (`https://api.basilic.localhost`, `GET /health`, `/reference`), web (`https://basilic.localhost` — login `test@test.ai`), eve (`https://agents.basilic.localhost/eve/command/v1/health` and `/eve/chat/v1/health`), docs (`https://docu.basilic.localhost`), email preview (`https://email.basilic.localhost`), and Pattern B package watchers. Mobile stays `pnpm --filter @repo/mobile start`. Generated projects omit `apps/agents` and `apps/docu`. If the Portless proxy is down, `pnpm dev` starts it on port 443 before Turbo (one sudo prompt). `pnpm setup` trusts the local CA.

## Manual

Separate terminals, always from the repo root (no `cd`):

- Postgres: `pnpm db:start`. Status: `pnpm db:status`. Stop: `pnpm db:stop`. Wipe: `pnpm reset`.
- API: `pnpm --filter @repo/api dev` — https://api.basilic.localhost
- Web: `pnpm --filter @repo/web dev` — https://basilic.localhost
- Agents: `pnpm --filter @repo/agents eve:dev` — https://agents.basilic.localhost/eve/command/v1/health and `/eve/chat/v1/health`
- Docs: `pnpm --filter @repo/docu dev` (this repo) — https://docu.basilic.localhost. Generated projects use `docs/basilic/` instead.
- Email: `pnpm --filter @repo/email dev` — https://email.basilic.localhost
- Mobile: `pnpm --filter @repo/mobile start`
- Bypass Portless: `pnpm --filter @repo/web dev:app` (and sibling `dev:app` scripts) or `PORTLESS=0`

**Apps:** `apps/api` (Fastify 5), `apps/web` (Next.js 16), `apps/mobile` (Expo 57), `apps/agents` (eve command and chat), `apps/docu` (Fumadocs).

**Packages:** `core`, `react`, `ui`, `utils`, `error`, `email`, `cli`, `db`. Catalog: [Packages](/docs/development/packages).
