Package manager is **pnpm 12.5.1** (see root `packageManager`). Decision: [ADR 005](/docs/adrs/005-package-manager). Lint split: [ADR 006](/docs/adrs/006-linters).

**Biome** formats and applies style (imports, unused). **ESLint** owns TypeScript, React, Next.js 16, Expo, and Fastify correctness. `pnpm lint` runs Biome then ESLint. Pre-commit formats staged files with Biome after security hooks. CI runs both (`lint.yml`).

Monorepo hygiene (also in `lint.yml` on every PR):

```bash
pnpm knip              # unused files (see knip.json)
pnpm sherif            # workspace dependency version alignment
pnpm openapi:drift     # regenerate OpenAPI + clients, fail on git drift
pnpm openapi:lint      # Redocly rules on apps/api/openapi/openapi.json
pnpm agentic:scan      # is-agentic score (set AGENTIC_SCAN_URL; operator-only)
pnpm db:studio         # Drizzle Studio (needs pnpm db:start + POSTGRES_URL)
```

```bash
pnpm lint
pnpm lint:fix
```

Turborepo caches `build`, `checktypes`, and `lint:eslint`. `test`, `test:unit`, and `test:e2e` are not cached (`cache: false` in `turbo.json`). `pnpm dev` uses the same TUI left pane as `pnpm lint:eslint` / `pnpm test` (`"ui": "tui"` in `turbo.json`). `@repo/agents#dev` depends on `@repo/db#db:start` so Postgres is up before eve boots. Per-package `build.env` in `turbo.json` hashes only vars that change emitted output (e.g. `VERCEL_GIT_COMMIT_REF` on `@repo/web#build` only). Consumer app builds no longer run OpenAPI codegen — use `pnpm generate` when API routes change.

## Root scripts

Run with `pnpm <script>` from the repository root.

**Setup:** `setup` (install, hooks, skills, gitleaks, osv, env templates, Portless, database, deepsec, Playwright Chromium), `setup:skills`, `setup:env`, `setup:portless`, `setup:database`, `db:start` / `db:stop` / `db:status`, `reset` (API wipe + migrate + seed).

**Primary:** `build`, `dev` (Portless proxy + Postgres, then Turbo TUI), `qa` (checktypes, lint, OpenAPI drift, build, unit and E2E).

**Quality:** `checktypes`, `format`, `lint`, `lint:fix`, `test`, `test:e2e`.

**Security:** `security:secrets`, `security:secrets:full`, `security:osv`, `security:audit`, `security:check`, `security:deepsec:scan`, `security:deepsec:process:diff`. Pre-commit: `hooks:pre-commit`.

CI: lint and `security.yml` on every PR. App E2E and package tests run when relevant paths change. See [GitHub Actions](/docs/deployment/github-actions).


## Build performance

Measure before and after build-graph changes. Cold run (clear caches first):

```bash
rm -rf .turbo
find . \( -name node_modules -o -name .git \) -prune -o \( -name dist -o -name .next \) -type d -prune -exec rm -rf {} +
find . \( -name node_modules -o -name .git \) -prune -o -name '*.tsbuildinfo' -delete
pnpm turbo run build --force --profile=turbo-profile.json --verbosity=1
pnpm checktypes
pnpm lint
pnpm turbo run build --filter=@repo/web... --force --profile=web.json --verbosity=1
pnpm turbo run build --filter=@repo/api... --force --profile=api.json --verbosity=1
pnpm turbo run build --filter=@repo/docu... --force --profile=docu.json --verbosity=1
```

Re-run the same commands after changes. OpenAPI regen: `pnpm generate` (not part of `@repo/web...` build).

## Turbo remote cache (optional)

For cross-machine cache hits, create a [Vercel Remote Cache](https://vercel.com/docs/monorepos/remote-caching) token and set `TURBO_TOKEN` + `TURBO_TEAM` in GitHub Actions secrets and Vercel project env. Per-package env keys (Phase 1a) must be in place first or branch secrets still bust package caches.
