The `@repo/cli` package is the **API CLI** (`basilic` binary): call the Fastify API with an API key. It is for developers, scripts, and agents operating in a shell. It is not the project generator.

The **project generator** is source-only `tools/create-basilic` (`0.0.0`, not on npm `latest`). Clone this repository, or assemble and run that CLI locally. Do not use `npx create-basilic@latest` until the package is published. See [Getting Started](/docs/development) and [`tools/create-basilic/README.md`](https://github.com/blockmatic/basilic/blob/main/tools/create-basilic/README.md).

The `@repo/cli` package uses `@repo/core` for all requests and supports only API key auth. Auth endpoints (magic link, OAuth, passkey, etc.) are excluded. Prefer `API_KEY` or `BASILIC_API_KEY` in non-interactive environments. Stdout is always JSON (`JSON.stringify`); there is no `--json` flag. Use `--help` on any command. Basilic does not ship an API MCP server.

## Auth

1. Env var: `API_KEY` or `BASILIC_API_KEY`
2. Config file: `~/.config/basilic/config.json`
3. Interactive prompt (saves to config)

```bash
basilic config set-api-key bask_xxx_yyy
```

## Commands

Commands mirror core API nesting: `health-check`, `account apikeys create`, `account apikeys list`, `ai generate`, etc. Use `--help` for OpenAPI-derived descriptions.

```bash
basilic health-check
basilic account apikeys list
basilic ai generate --prompt "Hello"
```

## Local testing

1. Start API: `pnpm dev`
2. Create API key via dashboard or `POST /account/apikeys/` with JWT
3. Run: `API_KEY=bask_xxx node packages/cli/dist/cli.js health-check`

See [packages/cli/README.md](https://github.com/blockmatic/basilic/blob/main/packages/cli/README.md) for full instructions.

## Agentic use

Prefer env auth (`API_KEY` or `BASILIC_API_KEY`) so the process is non-interactive. Stdout is JSON. Exit codes follow Commander. There is no product MCP; agents shell out to `basilic` and parse JSON.

```bash
result=$(basilic health-check)
```
