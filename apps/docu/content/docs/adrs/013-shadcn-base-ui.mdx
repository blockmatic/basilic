---
title: "ADR 013: Shadcn Base UI primitives"
description: "Adopt Base UI as the headless primitive layer under @repo/ui shadcn wrappers, replacing Radix."
---

Status: **Accepted.** Supersedes the primitive-library choice in [ADR 004](/docs/adrs/004-design-system) (shadcn + Tailwind remains). Landed with `components.json` style `base-vega`.

## Context

`@repo/ui` shipped shadcn/ui wrappers on Radix (`new-york`). shadcn now defaults new installs to Base UI. The wrappers were stock except tokens in `packages/ui/src/styles/tokens.css`. Apps compose via `@repo/ui/components/*`; they did not import `@repo/ui/radix`.

## Decision

Install and overwrite shadcn wrappers from the **Base UI** registry with visual style **`base-vega`** (New York successor). Keep Basilic tokens and `@repo/ui/components/*` import paths.

- Primitives: `@base-ui/react`. Rare direct composition: `@repo/ui/base` (never `@base-ui/react` or `@radix-ui/*` from apps).
- Composition: Base UI `render` (and `nativeButton={false}` when the rendered node is not a button), not Radix `asChild`.
- Parts: HTML `data-slot` (for example `data-slot="dialog-content"`). Open/checked: presence attrs `data-open`, `data-closed`, `data-checked` — Tailwind `data-open:*` / `data-checked:*`, not Radix `data-[state=open]`. `data-orientation` / `data-horizontal` / `data-vertical` for layout. ARIA stays for accessibility; do not treat `data-open` as ARIA.
- Future `shadcn add` must keep `"style": "base-vega"` in both `packages/ui/components.json` and `apps/web/components.json`.
- Next.js `Link` as a button: prefer `Link` + `buttonVariants()` when the node must be a real `<a>`. `Button` `render={<Link />}` can keep `role="button"`.

## Consequences

- App call sites that used `asChild` must pass `render`.
- CLI alias bugs can emit `from "cn"` or `IconPlaceholder`; rewrite to `@repo/ui/lib/utils` and lucide.
- Basilic `/w-*` playbooks install with `pnpm setup:skills` (`workflow` pack). Lock-installed `shadcn` / `/w-shadcn` describe this repo’s Base UI stack (`base-vega`, `render`, `data-*`).
- Import path stays `@repo/ui/components/*`. These Radix-era exports are gone: `NavigationMenuViewport`, `NavigationMenu` `viewport`, and `PopoverAnchor`. Use `NavigationMenuPositioner` and Popover `Positioner` (inside `PopoverContent`) instead. Do not restore compatibility shims.
