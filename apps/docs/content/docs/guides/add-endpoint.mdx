Complete walkthrough for adding a new API endpoint with full type safety.

## Overview

Adding an endpoint:
1. Define Fastify route with TypeBox schemas (native JSON Schema)
2. Generate OpenAPI spec from routes
3. Generate TypeScript clients with Zod schemas from OpenAPI
4. Use generated typed clients

## Step 1: Implement Server Route

Define TypeBox schemas and implement the Fastify route in `apps/api/src/routes/`:

```typescript
// apps/api/src/routes/users.ts
import { Type } from 'typebox'
import type { FastifyPluginAsync } from 'fastify'

// Define TypeBox schemas (native JSON Schema)
const UserParamsSchema = Type.Object({
  id: Type.String(),
})

const UserSchema = Type.Object({
  id: Type.String(),
  email: Type.String({ format: 'email' }),
  name: Type.String(),
})

const ErrorSchema = Type.Object({
  code: Type.String(),
  message: Type.String(),
})

const userRoutes: FastifyPluginAsync = async (fastify) => {
  fastify.get('/users/:id', {
    schema: {
      params: UserParamsSchema,
      response: {
        200: UserSchema,
        404: ErrorSchema,
      },
    },
  }, async (request, reply) => {
    // request.params is automatically typed from schema
    const { id } = request.params
    
    // Your implementation here
    const user = await getUserById(id)
    
    if (!user) {
      return reply.code(404).send({
        code: 'NOT_FOUND',
        message: 'User not found',
      })
    }
    
    return reply.send(user)
  })
}

export default userRoutes
```

## Step 2: Generate OpenAPI Spec

Generate the OpenAPI specification from your Fastify routes:

```bash
# Generate OpenAPI spec from routes
pnpm --filter @repo/api gen:openapi
```

This runs `generate-openapi.ts` which scans your Fastify route definitions and automatically generates the OpenAPI 3.0 spec at `apps/api/openapi/openapi.json`.

## Step 3: Generate TypeScript Clients

Run hey-api to generate TypeScript clients from the OpenAPI spec:

```bash
# Generate clients for core and react packages
pnpm --filter @repo/core gen
pnpm --filter @repo/react gen
```

This generates type-safe client code in:
- `packages/core/src/gen/` - Runtime-agnostic client
- `packages/react/src/gen/` - React Query hooks

## Step 4: Use Generated Typed Client

The generated client is fully typed:

```typescript
// In your frontend or other client
import { createApi } from '@repo/core'
import { useUser } from '@repo/react' // Generated React Query hook

// Runtime-agnostic client
const api = createApi({
  baseUrl: process.env.NEXT_PUBLIC_API_URL!,
  getAuthToken: async () => session?.token,
})

// Fully typed API call
const user = await api.getUser({ id: '123' })
// user is typed from OpenAPI spec

// Or use generated React Query hooks
const { data } = useUser({ id: '123' })
// data is typed as UserDTO | undefined
```
