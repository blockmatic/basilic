## Extension Roles in This Project

### Hybrid Linting Architecture

This monorepo uses a **hybrid linting architecture** where Biome and ESLint have distinct, non-overlapping responsibilities:

- **Biome**: Handles formatting, style, import organization, and unused code detection
- **ESLint**: Handles correctness, framework rules (React, Next.js), and architectural boundaries

**Important**: All formatting rules are disabled in ESLint configs. Biome owns formatting completely.

### Workflow Integration

- **CodeRabbit**: Used during [Phase 3: Execution](/docs/cursor-workflow/complete-workflow#phase-3-execution) for pre-commit review and [Phase 4: Review](/docs/cursor-workflow/complete-workflow#phase-4-review--refinement) for PR reviews
- **Biome**: Run via `pnpm lint:biome` or `pnpm format` for formatting (see [Phase 3: Execution](/docs/cursor-workflow/complete-workflow#phase-3-execution))
- **GitHub Actions**: Provides IntelliSense and validation for `.github/workflows/*.yml` files
- **Tailwind IntelliSense**: Enhances productivity when working with Tailwind CSS classes
- **Mermaid Extensions**: Enable diagram visualization in Markdown files and documentation

### Mermaid Diagram Support

This project uses Mermaid diagrams extensively for:
- Architecture documentation
- User journey visualization
- Roadmap planning
- Code visualization

**Two Mermaid extensions work together:**
- **Markdown Preview Mermaid Support**: Renders diagrams in VS Code's built-in Markdown preview
- **Mermaid Chart**: Provides syntax highlighting, live preview, and export capabilities

Both extensions complement each other - use Markdown Preview for quick viewing, and Mermaid Chart for advanced editing and export features.

## Installation

Install all recommended extensions via Extensions panel (Cmd/Ctrl + Shift + X) or use the workspace recommendations file (`.vscode/extensions.json`).
