## Learning Path

**New to Cursor?** Start here:

1. **Quick Start** → Read [Quick Start Guide](/docs/cursor-workflow/quick-start) for essential patterns (5 min)
2. **Full Workflow** → Read [Complete Workflow](/docs/cursor-workflow/complete-workflow) for complete development lifecycle
3. **Tool Setup** → Read [Extensions Guide](/docs/cursor-workflow/extensions) when setting up your environment

**Experienced user?** Jump directly to:
- [Complete Workflow](/docs/cursor-workflow/complete-workflow) - Complete reference with all phases, commands, and best practices
- [Extensions Guide](/docs/cursor-workflow/extensions) - Extension configuration and usage

### [Quick Start](/docs/cursor-workflow/quick-start)

### [Complete Workflow](/docs/cursor-workflow/complete-workflow)

- Mermaid diagram support
- GitHub Actions workflow support
