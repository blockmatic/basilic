# Technology Stack

## Frontend Technologies
- **Framework**: Next.js (15.5)
- **UI Libraries**:
  - React (18.2-19.2)
  - Tailwind CSS
  - Shadcn UI (with Radix UI primitives)
  - Framer Motion
  - Lucide React (icons)
  - Class Variance Authority (cva)
- **Form Handling**: TanStack React Form
- **State Management**: 
  - React Hooks
  - TanStack Query (React Query)
  - SWR
- **Content Management**: ContentLayer
- **Styling**: 
  - Tailwind CSS
  - PostCSS
  - tailwind-merge
- **Utilities**: 
  - clsx
  - zod (form validation)
  - date-fns

## Backend Technologies
- **Framework**: NestJS
- **Database**:
  - PostgreSQL
  - Supabase
  - PlanetScale
- **API**: 
  - REST APIs
  - next-safe-action
- **Authentication**: 
  - NextAuth
  - SIWE (Sign In With Ethereum)

## Web3 Technologies
- **Smart Contracts**: Solidity with Foundry
- **Client Libraries**:
  - Viem (v2)
  - Wagmi (v2)
  - RainbowKit
  - ThirdWeb
- **Indexing**: Ponder (Ethereum indexer)

## DevOps & Tooling
- **Package Managers**:
  - pnpm
  - Bun
- **Build Tools**:
  - TurboRepo
  - tsup
- **Code Quality**:
  - TypeScript (5.2-5.9)
  - Biome (linting/formatting)
  - simple-git-hooks
- **Infrastructure**: Docker
- **Analytics**: Vercel Analytics

## Testing
- **Testing Framework**: Jest (implied from configurations)

## Deployment
- **Hosting**: Vercel (implied from Vercel-specific packages)

This tech stack demonstrates a modern, full-stack development environment with a strong focus on TypeScript, React/Next.js for frontend, and Web3 technologies. The use of monorepo tools like TurboRepo suggests a well-organized codebase with shared packages and standardized development practices.
