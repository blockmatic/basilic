Generate a high-quality v0.dev prompt based on the current file, selection, and repository context.

Constraints for the generated prompt:
- Stack: Next.js App Router
- Language: React + TypeScript
- Styling: Tailwind CSS
- UI: shadcn/ui
- Server Components by default
- Client components only when strictly necessary
- Accessible, semantic HTML
- Mobile-first, responsive layout
- Clean, minimal, production-ready design
- No data fetching or mock APIs unless explicitly required
- Follow existing layout, spacing, and component patterns in the repo
- Max 300 lines per any file
- Max 1 react component per file

Validation steps (must happen before opening v0.dev):
1. Show the generated v0 prompt to the user.
2. Ask the user to validate it with a single explicit choice:
   - Reply "OPEN" to open v0.dev with this prompt
   - Reply "EDIT:" followed by changes to revise the prompt
   - Reply "CANCEL" to stop
3. If user replies "EDIT:", revise the prompt and repeat validation steps (1–2).
4. Before opening, ensure:
   - The prompt is concise and does not include repo-internal paths, secrets, or private tokens.
   - The prompt avoids irrelevant implementation details.
   - The URL-encoded prompt length is within typical browser URL limits; if too long, ask the user to shorten/scope it.

Action (only after user replies "OPEN"):
1. URL-encode the final approved prompt.
2. Open the browser at:
   https://v0.dev?chat={url_encoded_prompt}

Output rules:
- During validation: output only the prompt (plain text) and the OPEN/EDIT/CANCEL instruction line.
- After opening: output only "Opened v0.dev".
- Do not output the URL.
