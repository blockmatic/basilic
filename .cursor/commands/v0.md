# Generate v0.dev Prompt

Generate high-quality v0.dev prompt based on current file, selection, and repository context.

## Constraints
- Stack: Next.js App Router
- Language: React + TypeScript
- Styling: Tailwind CSS
- UI: shadcn/ui
- Server Components by default
- Client components only when strictly necessary
- Accessible, semantic HTML
- Mobile-first, responsive layout
- Clean, minimal, production-ready design
- No data fetching or mock APIs unless explicitly required
- Follow existing layout, spacing, and component patterns in repo
- Max 300 lines per file
- Max 1 react component per file

## Validation Steps
1. Show generated v0 prompt to user
2. Ask user to validate with single explicit choice:
   - Reply "OPEN" to open v0.dev with this prompt
   - Reply "EDIT:" followed by changes to revise prompt
   - Reply "CANCEL" to stop
3. If user replies "EDIT:", revise prompt and repeat validation steps (1–2)
4. Before opening, ensure:
   - Prompt is concise, no repo-internal paths/secrets/private tokens
   - Prompt avoids irrelevant implementation details
   - URL-encoded prompt length within browser URL limits; if too long, ask user to shorten/scope it

## Action (only after user replies "OPEN")
1. URL-encode final approved prompt
2. Open browser at: `https://v0.dev?chat={url_encoded_prompt}`

## Output Rules
- During validation: output only prompt (plain text) and OPEN/EDIT/CANCEL instruction line
- After opening: output only "Opened v0.dev"
- Do not output the URL
