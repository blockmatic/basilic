Systematically set up new feature from planning through implementation structure. Follow @.cursor/rules/base/general.mdc for planning discipline.

1. **Gather context**: Read readme, docs, skills, rules before planning and coding
2. **Define requirements**: Clarify scope/goals, identify user stories/acceptance criteria, plan technical approach
3. **Summarize assumptions**: List 3–5 bullets before detailed planning
4. **Create feature branch**: Branch from main/develop, set up local dev, configure dependencies
5. **Plan architecture**: Design data models/APIs, plan UI components/flow, consider testing strategy, document requirements
6. **Output structure**: Add ## References section listing cursor rules files and cursor skills used
7. **Defer when uncertain**: Defer to user for ambiguous, high-risk decisions
