# Contributing

Fork this repository to contribute upstream. New products use `npx create-basilic@latest my-app` ([Getting Started](https://basilic-docs.vercel.app/docs/development)); do not clone this tree as a product start. The generator is not on npm `latest` yet (`0.0.0` in tree); until it is, assemble and run it from this repository.

1. Read [Getting Started](https://basilic-docs.vercel.app/docs/development) and [After fork](https://basilic-docs.vercel.app/docs/development/after-fork).
2. Follow root `AGENTS.md` and Conventional Commits.
3. Run `pnpm qa` before opening a pull request.
