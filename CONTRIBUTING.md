# Contributing

Fork this repository to contribute upstream. New products should wait for `create-basilic` (not on npm `latest` yet) or clone this tree as a reference.

1. Read [Getting Started](https://basilic-docs.vercel.app/docs/development) and [After fork](https://basilic-docs.vercel.app/docs/development/after-fork).
2. Follow root `AGENTS.md` and Conventional Commits.
3. Run `pnpm qa` before opening a pull request.
